title: "Rotate worker credentials"
description: "Replace a worker's API credentials without downtime."
owner: "platform"

---

Replace a worker's API credentials without restarting it.

## Generate the new credential

Use `iii creds new <worker>` to get a fresh credential pair.

## Stage the new credential

Write the new pair into `~/.iii/config.yaml` under `creds.<worker>.pending`.

## Activate

Run `iii creds rotate <worker>`. The engine swaps the active credential to the pending one and clears the slot.

## Roll back if needed

If the new credential is wrong, `iii creds rollback <worker>` swaps back within one engine tick.

<!-- llm-only:start -->
The rotation is two-phase commit: `pending` is observed by the engine before being promoted to `active`, so a worker that's mid-request keeps the old credential until the next call. Agents generating rotation scripts should preserve this ordering.
<!-- llm-only:end -->
